# 已知限制与状态边界

| 项目 | 当前边界 |
| --- | --- |
| 样本范围 | 10份自制、21页；无真实案件材料验收，不能外推一般准确率。 |
| 原生文字已核验 | 仅比较Markdown与来源文字、来源区域与PDF原生文字层；不验证图像遮挡、隐藏文字或文字层与肉眼画面一致。 |
| OCR | 复用Docling本地Vision接口，文字及坐标均是待人工核对候选；不能用相同OCR结果证明OCR正确。 |
| OCR漏段 | 没有独立原生文字层，无法全面发现扫描识别遗漏；扫描整页仍须复核。 |
| 精确程度 | 文本块或单元格区域；不声称查到的是某几个字的精确框。跨页摘录允许多个来源。 |
| 印刷页码 | 原生页脚只识别明确的“第…页”；双候选列歧义。罗马数字或纯数字页脚未自动认定；PDF内部标签另列。 |
| 表格 | 不自动拼表、不推断续行归属；上游表头合成、单元格跨度与Markdown展平可能导致导出一致性未通过。 |
| 文字变化 | 仅忽略空白，不替换标点、金额、数字或繁简体，不核验任意AI概括。 |
| Markdown被清理 | 编号可能被知识库移除，届时报告关联丢失；不能保证靠文字搜索恢复来源。 |
| 稳定编号 | 同文件、锁定运行环境及配置下确定；改文件或升级解析器、OCR系统后须重测，不承诺编号不变。 |
| 哈希 | 检查字节一致性；不是司法真实性、可信来源或防恶意篡改签名。 |
| 完整复现 | 本机macOS arm64实测，复用基础Python、uv、系统Vision；不是独立新操作系统、跨平台或隔离系统OCR模型的证明。 |
| 离线范围 | 安装和资源下载联网；处理和测试在系统禁止联网沙箱运行。Python socket审计不能替代针对任意原生扩展的系统防火墙。 |
| 分发范围 | 分发本工具源码与自制样本；第三方依赖、模型及字体分别适用各自条款。资源下载不包含用户PDF。 |

record.status的verified需要文字与位置两层检查通过；needs_review不能计为verified；unresolved或unsupported须查看原因。整体报告issues_found也可能只由印刷页码歧义触发，不能凭一个总状态推断整份文件完全不可用。

测试通过说明程序按预设要求处理成功、失败和不支持，不等于每条摘录全部成功。第二阶段基线100条中76条已核验、22条待核对、2条导出一致性未通过，详见 [测试说明](testing.md)；升级后以新回执为准。

尚未验证大体量PDF、密码保护、复杂旋转裁切、异常字体、手写批注、真实印章、恶意PDF，以及跨系统OCR结果。上游的弃用警告仍存在；升级时不可直接沿用本次结果。
